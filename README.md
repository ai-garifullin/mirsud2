# Mirsudhelp — Система технической поддержки Мировых Судей РТ

Комплексная информационная система для автоматизации процессов технической поддержки, обработки обращений (HelpDesk), а также управления сопутствующими задачами инфраструктуры мировых судей. Проект состоит из нескольких веб-интерфейсов (на базе Streamlit) и фоновых сервисов, работающих в единой Docker-инфраструктуре.

## 🗂 Структура и основные модули

Система разделена на несколько независимых, но взаимосвязанных компонентов:

- **Портал пользователя (`form_app.py` - порт 8502):**
  Интерфейс для подачи заявок. Включает встроенную "Экспертную систему" для помощи в самостоятельном решении типовых проблем на базе интерактивных опросников.
  
- **Дашборд диспетчера (`dashboard.py` - порт 8501):**
  Интерфейс для ИТ-специалистов. Позволяет отслеживать, фильтровать, брать в работу и закрывать заявки пользователей.

- **Панель администратора (`admin_panel.py` - порт 8505):**
  Единая точка доступа к утилитам для администраторов системы:
  - Редактор базы знаний и экспертной системы (`edit_kb.py`).
  - Редактор информационной доски (`edit_board.py`).
  - Генератор актов неисправности (`diagnostic_act.py`).
  - Управление облачными файлами (`cloud_files.py`).
  - Генератор VBS скриптов (`croc.py`).
  - Калькулятор ЗП (`salary.py`).

- **Фоновые сервисы (Боты):**
  - `service_desk_bot.py` / `not_bot.py`: Telegram-боты для автоматических уведомлений о статусе заявок и взаимодействия с диспетчерами.
  - `email_monitor.py`: Сервис для автоматического сбора заявок, поступающих через электронную почту.

## 🛠 Стек технологий

- **Backend / Frontend:** Python 3.9, [Streamlit](https://streamlit.io/)
- **База данных:** MySQL 8.0
- **Контейнеризация:** Docker, Docker Compose
- **Интеграции:** Telegram Bot API, Yandex Disk API (для облачных файлов), python-docx (для генерации актов)

## 🚀 Запуск проекта

Проект полностью контейнеризирован и готов к запуску через Docker Compose.

### Предварительные требования
1. Установленные Docker и Docker Compose.
2. Настроенный файл окружения `.env` в корне проекта (содержит пароли от БД, токены Telegram-ботов, настройки почты и т.д.).

### Установка и запуск

1. Склонируйте репозиторий или перейдите в папку с проектом.
2. Выполните команду для сборки и запуска всех сервисов:
   ```bash
   docker-compose up -d --build
   ```

### Доступ к сервисам после запуска

После успешного старта контейнеров, сервисы будут доступны по следующим адресам (если запуск локальный):
- **Дашборд диспетчера:** [http://localhost:8501](http://localhost:8501)
- **Форма заявки:** [http://localhost:8502](http://localhost:8502)

- **Админ-панель (Всё-в-одном):** [http://localhost:8505](http://localhost:8505)

*База данных MySQL проброшена на порт `3307` для возможности внешнего подключения и администрирования.*

## 📁 Структура данных
- `attachments/` — директория для хранения файлов, прикрепляемых к заявкам пользователей.
- `logs/` — логи работы фоновых скриптов и ботов.
- `init.sql` — скрипт инициализации структуры базы данных.
- `knowledge_base.json` / `info.json` — конфигурационные файлы базы знаний и информации на главной странице.
